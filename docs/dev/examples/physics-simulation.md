# 物理仿真示例

本示例在**仿真实验室**里完成一次完整的物理实验：选一个内置场景、运行仿真、调整参数、记录并导出数据。

文中每一步都对应页面上真实存在的按钮或输入框，不含任何需要复制粘贴的代码。

## 第一步：选择一个内置场景

仿真实验室顶部的工具栏右侧有一个预设下拉框，默认显示“选择预设...”。展开后有 6 个内置场景：

| 预设 | 包含的物体 |
| --- | --- |
| 牛顿摆 | 一个“支架”与 5 个“摆球 N”，摆球沿 X 排成一列 |
| 斜坡与球体 | 一块“地面”、一块“斜坡”与 3 个大小不同的球体 |
| 碰撞测试 · 多形状 | 一块“地面”、一个“立方体”、一个“球体”与一个“圆柱体” |
| 自由落体 | 一个“立方体”和一个“球体”，起始高度均为 5，X 分别为 0 与 2 |
| 双立方体碰撞 | 两个立方体，分别位于 X 为 -2 与 2 处，高度为 1 |
| 钟摆 | 一个缩放为 0.5 的方块“摆球”，位于高度 3 处 |

选择任意一项后，画面中立刻生成对应的物体，同时重新初始化物理世界，仿真时间归零，页面顶部提示“已加载预设: <预设名>”。

## 第二步：运行与控制仿真

工具栏左侧的按钮组按从左到右的顺序是：

| 按钮 | 作用 |
| --- | --- |
| 播放 / 暂停 | 开始或暂停仿真，图标在两者间切换 |
| 单步仿真 | 手动推进一个固定步长（1/60 秒，约 0.0167 秒），仿真时间同步增加同样的数值 |
| 重置仿真 | 停止仿真、仿真时间归零、移除全部物理物体、重建物理世界，并重新加载当前预设 |
| 删除选中物体 | 删除当前选中的物体，没有选中时按钮为灰色 |

工具栏中间是**仿真速度**滑块，取值范围 0.1 到 5.0，步进 0.1，右侧实时显示当前倍率。速度是**倍率**：1× 表示仿真时间与真实时间同步，2× 表示同样的真实时间里推进 2 倍的仿真时间。**物理步长恒为 1/60 秒**，倍率改变的只是“每秒推进多少个步”，不改变步长本身。

> 倍率越高，同样的真实时间内推进的物理步越多：5× 时每真实秒约推进 300 步。步长不变，所以不存在“步长变大导致数值不稳定”的问题。单个渲染帧最多推进 `maxSubSteps`（5）步，多余的积压会被丢弃（否则低帧率机器会陷入“追帧→更卡→更少帧”的死循环）。

## 第三步：调整实验参数

右侧的“实验参数”面板分两组：

**环境设置**

| 参数 | 默认值 | 生效方式 |
| --- | --- | --- |
| 重力 | -9.8 | 输入后失焦即写入物理世界的重力向量（只作用于 Y 轴） |
| 摩擦力 | 0.1 | 输入后失焦即遍历场景，更新所有碰撞体的摩擦系数 |
| 弹性系数 | 0.5 | 输入后失焦即遍历场景，更新所有碰撞体的恢复系数 |

每次修改都会在页面顶部弹出提示，例如“重力已设置为 -9.8”。

摩擦力与弹性系数是**按碰撞体批量更新**的，会同时作用到场景中的全部物理物体，不能针对单个物体单独设置。

> 补充：面板里摩擦力与弹性系数的**默认值不会一进页面就下发**——那样会把预设里逐个物体的参数抹平。只有你真的动过这两个输入框（或恢复了已保存的实验配置），它们才会作为全局覆盖生效。

## 第四步：记录并导出数据

“数据记录”分组提供三个控件：

1. 勾选**记录仿真数据**。该选项只有在仿真运行中才会开始产生数据。
2. 设置**采样间隔**（单位秒，最小 0.01，默认 0.1）。实际采样频率取决于仿真时间累积到多少才超过这个间隔。
3. 面板会显示“已记录: N 帧”。当帧数大于 0 时，**导出数据**按钮出现。

点击**导出数据**后，浏览器会下载一个名为 `simulation-data-<时间戳>.json` 的文件，内容是按时间排列的帧记录，每帧包含时间戳以及各物理物体当时的位置。

## 第五步：保存实验配置

点击工具栏上的**保存实验配置**（软盘图标），当前的重力、摩擦力、弹性系数、仿真速度、是否记录数据与采样间隔会被打包写入浏览器的 `localStorage`，键名为 `experimentConfig`，页面提示“实验配置已保存”。

**这份配置会被读回**：下次打开仿真实验室时，页面初始化阶段会读出上次保存的 6 项参数并填回界面，重力、摩擦力与弹性系数同时**真正作用到物理世界**上（物理世界建好后会重新下发一次），仿真速度也照常生效。数据损坏时保持默认值，不会让页面崩。

> 限制：配置保存在浏览器 `localStorage` 里，换浏览器、换设备或清掉站点数据就没了；需要长期留存请自行导出。

## 从场景编辑器加载场景

工具栏右侧有两个配合使用的控件：一个标题为“选择已保存场景...”的下拉框，以及一个文件夹图标的按钮（标题为“从场景编辑器加载场景”）。

1. 下拉框列出场景编辑器保存过的场景，格式是 `<名称>（<N> 个物体）`；一个都没保存过时，那个文件夹按钮是禁用的。
2. 选中一个场景后点文件夹按钮：实验室会移除当前所有物体，**读取场景编辑器真正存下来的场景文档**（`localStorage` 里的 `scene-<id>`），按文档记录的位置、旋转与缩放重建物体，模型按 `modelId` 重新加载，随后重新初始化物理世界，页面提示“已从场景编辑器加载: <名称>”。
3. 没有先在下拉框里选场景就点按钮，页面提示“请先在工具栏里选择一个已保存的场景”。

> 限制：从编辑器加载过来的物体使用实验室侧的默认摩擦力与弹性系数（0.5 / 0.2）——场景编辑器本身没有单物体的物理参数控件，也就不会保存这些值。

顺带一提，页面首次进入时也会自动创建两个**硬编码的演示物体**——“演示立方体”和“演示球体”，位置分别在 `(0, 3, 0)` 与 `(2, 3, 0)`，因此不选预设也能直接开始仿真。点「重置仿真」而当前没有选预设时，跑的也是同一段演示场景创建逻辑；点「从场景编辑器加载场景」时，演示物体则会被场景文档里的物体替换掉。
