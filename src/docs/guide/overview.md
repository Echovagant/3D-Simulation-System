# 系统总览

这个系统由六个页面组成。这里只说三件事：**每个模块是什么**、**它的参数到底怎么理解**、**数据存在哪里**。
按钮怎么点不在这里写——界面自己会告诉你；真正需要查的是「已知问题与边界」那一页。

## 六个模块

### 场景编辑器 `/scene-editor`

搭场景：加几何体与模型、调位置/旋转/缩放、跑物理、把场景存下来。

- 初始场景是**空的**，物理模拟**自动开启**——加完几何体它就会往下落，不用再点「开始」。
- 属性面板的「位置/旋转/缩放」是**世界坐标**；旋转单位是**度**（内部换算成弧度）。改完要**失焦**才生效。
- 「重置模拟」把物体复位到**创建时**的初始变换，不是你在面板里最后摆的位置。

### 仿真实验室 `/simulation-lab`

独立的物理实验台：跑预设场景、调实验参数、记录并导出数据。它**不依赖**场景编辑器，两边各有各的场景与物理世界。

- 预设 6 个：牛顿摆、斜坡与球体、碰撞测试 · 多形状、自由落体、双立方体碰撞、钟摆。
- **物理步长恒为 1/60 秒**；「仿真速度」是倍率，改的是**每秒推进多少步**，不改变步长。
- 摩擦力与弹性系数是**全局批量生效**的——作用于场景里每一个物体。

### 模型库 `/model-library`

浏览模型资产并送进场景编辑器。库内 9 个条目全部指向真实文件，都能真正加载。

### AI 演武场 `/ai-playground`

配置环境、创建智能体、跑仿真、看决策日志。3D 视图会真实渲染，智能体是 Rapier 刚体，会跑会撞。

- 决策默认由**本地规则**产生（不是模型推理，也不做训练）。
- LLM 是**可选增强**：默认关闭，不填 Key 就没有任何出网请求。

### 批量仿真（仿真实验室右栏）

同一个场景按一组参数跑很多遍，产出可横向对照的结果。后端执行，用的是与前端**同一套物理引擎**。

- **扫描一次只扫一个维度**，不是笛卡尔积：选「摩擦」再填 `0.1, 0.5, 0.9` 就是跑 3 次，每次摩擦不同、其余参数相同。
- 步数是**物理步**，不是渲染帧。

### 服务端渲染（仿真实验室右栏）

提交场景与一段动作脚本，服务端产出 MP4。无头浏览器按脚本**逐帧推进物理**，抓帧编码成视频。

- 动作类型只有四种：`addCube` / `addSphere` / `setCamera` / `setSpeed`。
- 同一个场景重跑，**帧数完全一致**（第 N 帧严格对应第 N 个物理步）。

## 数据存在哪里

| 数据 | 存在哪 | 换设备/清缓存后 |
| --- | --- | --- |
| 场景 | 浏览器 `localStorage`，键名 `scene-<时间戳>` | **没了** |
| 实验配置（重力/摩擦/弹性/速度/采样） | 浏览器 `localStorage`，键名 `experimentConfig` | **没了** |
| 模型库上传的条目 | **只在当前会话的内存里** | **没了**（刷新即失效） |
| LLM Key（自带 Key 模式） | 当前页面的内存 | 刷新即失效 |
| LLM Key（托管模式） | 后端加密保管 | 取决于后端配置 |
| 批量仿真任务与结果 | 后端数据库 | 在后端 |
| 渲染视频产物 | 后端 `backend/backend_data/renders/` | 在后端 |

**系统没有账号体系，也没有云端同步。** 所有「保存在本地」的东西都只属于这台设备上的这个浏览器。

## 模块之间怎么串

```
模型库 ──(选模型 → 跳回)──> 场景编辑器 ──(保存场景)──> 仿真实验室
                                                  ├──(提交场景)──> 批量仿真
                                                  └──(提交场景 + 动作)──> 服务端渲染
```

场景编辑器保存的场景，在仿真实验室工具栏的下拉框里能选到；也可以用「从场景编辑器加载场景」按钮直接读取场景文档并重建物体（连 Rapier 刚体一起建好，所以照样会下落）。

## 哪些能力**没有**

- 没有账号、没有云同步、没有多人协作。
- 没有训练：AI 演武场的 LLM 只做决策与解释，不学习、不微调。
- 没有单物体物理参数：质量/摩擦/弹性只能在仿真实验室按全局调。
- 没有灯光与相机的编辑界面（初始化时自动创建）。
- 场景类型只实现了「导航挑战」，胜利条件只实现了「到达目标」。

更细的边界见 [已知问题与边界](./known-issues.md)。
