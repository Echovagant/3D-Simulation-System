# 已知问题与边界

这一页只写**你在界面上点不出来、也猜不到**的事：某个行为为什么这样、有哪些做不到、撞上了怎么办。

界面本身会回答「这个按钮在哪、点了会发生什么」；这里回答的是「为什么我做不到」。

## 全局

**「后端不在」时，功能会少掉哪些？**
只有三处依赖后端：**批量仿真**、**服务端渲染**、**LLM 托管模式**。其余一切——场景编辑、实时仿真、模型浏览、实验记录导出——完全不受影响。面板上会显示一句「后端不在，××暂不可用」，其余界面照常。

**换个浏览器/换台设备，我的东西还在吗？**
不在。场景、实验配置、上传的模型全都存在浏览器本地（见 [系统总览](./overview.md) 的数据表），系统没有账号也没有云端同步。

## 场景编辑器

**我改完位置，输入框又跳回别的数字了。**
播放中，物理每一步都在改物体的位置，所以手工设置的值会被覆盖。
→ **先点工具栏的「暂停模拟」再摆**。暂停只停物理推进、不停渲染：画面照常刷新，相机也还能转。

**「重置模拟」为什么没回到我摆的位置？**
它复位的是物体**创建时**的初始变换，不是你在属性面板里最后设的那个位置。
→ 想让某个位置成为「初始位置」，重新摆一次再重置。

**我找不到设置质量/摩擦/弹性的地方。**
属性面板没有这些控件，场景编辑器**无法给单个物体单独设物理参数**。
→ 这些参数在仿真实验室的实验参数面板里按**全局**生效。

**从存档里打开场景后，物体的 id 变了。**
基本体是「重新创建」的，存档里的 uuid 不再复用。
→ 别在外部按 uuid 引用场景里的物体。

**导入的模型为什么不在原点？**
落点是**随机出生点**（X/Z 在 -2.5 ~ 2.5，Y = 2），不是原点。
→ 用属性面板把它移到你要的位置。

**场景编辑器能不能加灯光/相机？**
不能，界面里没有这个入口。环境光、平行光、网格辅助线与轨道相机都在初始化时自动创建。

## 仿真实验室

**「钟摆」预设为什么不像摆子？**
它**没有实现摆的约束**，和其他预设一样只是自由落体。
→ 当成自由落体用，别拿它验证摆的物理。

**我只想调某一个物体的摩擦力，行吗？**
不行。摩擦力与弹性系数是**批量生效**的：改动会同时作用于场景里的每一个物理物体。
→ 要单独调某个物体，目前只能去场景编辑器（但那里也没有这些控件）。这是已知缺口。

**我什么都没动，实验参数却把预设里逐个物体的参数抹平了。**
默认值**不会**一进页面就下发——那会覆盖预设里逐个物体的设定。只有你真的动过输入框（或恢复过已保存的实验配置），它们才作为全局覆盖生效。

**「从场景编辑器加载场景」按钮是灰的。**
要先在工具栏下拉框里**选中**一个场景，按钮才可用。
→ 一个场景都没保存过时它会一直是灰的。

**从编辑器加载过来的物体，摩擦和弹性不对。**
它用的是**实验室侧的默认值**（0.5 / 0.2），不是编辑器里的设定——编辑器本身不保存这些参数。

**进页面就看到两个物体？**
那是硬编码的演示物体（演示立方体 + 演示球体），不选预设也会创建。

**速度调到 5× 会不稳吗？**
不会。**物理步长恒为 1/60 秒**，倍率改的只是每秒推进多少步。
→ 单帧最多补 5 步，多余的积压会被丢弃（否则低帧率机器会陷入「追帧→更卡→更少帧」的死循环）。

## 模型库

**我上传的模型刷新后没了。**
上传**没有真正保存文件**：文件对象不写入任何持久化位置，只在当前会话里可用（用 `blob:` 对象地址）。
→ 界面用 `sessionOnly` 标注了这一点。想长期用，请把文件放进 `public/assets/models/` 并更新模型清单。

**上传的模型显示「待分析」。**
多边形数、材质数、是否含动画**没有解析**，所以不编数字。
→ 内置的 9 个条目有真实值（并有闸门逐项核对）；上传的条目确实没有这些数据。

**删除条目后刷新又回来了。**
删除只影响当前会话的内存数据。
→ 同上，持久化只对内置的 9 个条目有效。

**上传日期看着很奇怪。**
内置条目的日期是按**固定种子**确定性生成的（同一个种子永远同一个日期），为了让测试与截图可复现——它不代表真实入库时间。

**详情弹窗里的大图不是 3D 预览？**
对，那是**缩略图图片**。真正的 3D 预览要进场景编辑器才看得到。

**内置模型长得很像玩具。**
9 个模型全部是本仓库**程序化生成的低多边形**资产，造型偏风格化，不是写实素材；仓库不含任何第三方模型。

## AI 演武场

**智能体的行为是真的推理出来的吗？**
默认**不是**。默认是写死的规则控制器：感知到障碍物就转，否则朝目标走。每一帧都一样，可复现。
→ 想看大模型驾驶刚体，需要自己填 Key 并把「决策来源」切到「LLM 决策」。

**智能体不会翻跟头。**
它被建模成**不自转的滑块**（锁死了自转），不做翻滚、堆叠与翻越。

**场景类型只有「导航挑战」能用。**
「物体交互」与「对抗模拟」尚未实现（需要智能体之间的交互与对抗机制）。胜利条件也只实现了「到达目标」，界面只能创建基础型智能体。

**改了环境设置为什么不用点「应用设置」？**
改动**立即生效**（障碍物密度按 150 毫秒防抖，因为它要重建整块场地）。「应用设置」是一次性提交全部字段的按钮。

**LLM 决策偶尔不动 / 变慢。**
护栏是刻意设的：两次请求至少间隔 1.5 秒、单次超时 15 秒、一次会话最多 60 次。
→ 超时或返回不可解析时**这一拍自动回落到规则式**，面板上会标「已降级」；失败后 5 秒内不重试。

**换成别的模型 / 改端点后请求被浏览器拦了。**
端点与模型 id 写在 `src/config/llmProviders.ts`，但 `index.html` 里的 CSP `connect-src` 要与它**一一对应**——少一个域名浏览器就会直接拦掉请求。
→ 改端点时同步改 CSP 那一串域名。

**部分模型报 400（`requires adaptive thinking`）。**
有些模型不允许关闭思考。客户端只在官方文档明确写了 `reasoning_effort` 的服务商上带这个参数，其余一律不发。
→ 换模型时按该模型的官方文档对一下。

**想要训练、多智能体协作、智能体记忆。**
尚未实现，本系统不做承诺。LLM 只做决策与解释。

## 批量仿真

**提交后提示队列不可用。**
批量仿真走 Redis 队列，要另起一个 worker 进程：`cd backend && uv run arq app.workers.simulation.WorkerSettings`。
→ 队列不通时服务端直接返回 503，任务不会被收下。

**提示当天次数用完了。**
每天最多 2000 次运行，按当天已产生的运行次数计。
→ 超出返回 429，隔天自然恢复。

**提示参数非法。**
单个任务最多 32 次运行、单次运行最多 10000 步。
→ 超出返回 422。

**场景里的模型没被算进去。**
只支持立方体与球体，其它类型（包括模型）会被跳过；场景里一个可渲染物体都没有时判为场景无效。

**改了步长 dt 之后，结果和浏览器对不上了。**
dt 必须是 1/60 秒才能和浏览器端逐位一致。改了它，一致性基线就失效了。

## 服务端渲染

**提示没有生产产物。**
渲染页在**生产产物**里，先跑 `npm run build`。
→ 开发服务器（`npm run dev`）打不开渲染页，这是设计如此。

**提示找不到 Chrome / ffmpeg。**
服务端渲染要真的跑起来，三样东西缺一不可：生产产物、Chrome、ffmpeg。
→ 路径可以用环境变量 `CHROME_PATH` / `FFMPEG_PATH` 覆盖。

**宽高填了奇数被拒。**
H.264 的 yuv420p 要求宽高都是偶数。
→ 单次最多 3600 帧，最长 600 秒。

**渲染的时候机器很忙。**
渲染会拉起一个无头浏览器进程并逐帧抓图，期间这台机器的 CPU 会被吃掉一块。
