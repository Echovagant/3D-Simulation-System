# 场景编辑器使用指南

场景编辑器（路由 `/scene-editor`）用于搭建 3D 场景：添加几何体与模型、调整它们的变换属性、运行物理模拟，并把场景数据保存到浏览器本地。

本章描述的都是当前版本**实际具备**的能力；受限之处在最后一节单独列出。

## 页面结构

页面自上而下分为三块：

1. **顶部工具栏**（`src/components/three/panels/Toolbar.vue`）：一排图标按钮与一个状态提示区。
2. **中间 3D 视口**（`src/components/three/panels/Viewport.vue`）：渲染画布，支持轨道相机。
3. **右侧属性面板**（`src/components/three/panels/PropertyPanel.vue`）：宽 300 像素，显示选中物体的变换参数。

页面加载时会有“SceneEditor场景初始化中...”的遮罩；初始化失败时改为显示错误信息与“重试”按钮。

初始化成功后系统会**自动添加立方体并自动开启物理模拟**，因此你看到的初始画面里物体已经在下落。

## 工具栏按钮

工具栏共有 7 个按钮。按钮本身只有图标，鼠标悬停时会显示标题。

| 按钮标题 | 实际行为 |
| --- | --- |
| 开始模拟 / 暂停模拟 | 同一个按钮，标题随播放状态切换。调用仓库的 `togglePlayStateWithTransition()`，切换期间会短暂锁定重复点击 |
| 重置模拟 | 调用 `store.resetSimulation()`：把每个物体复位到**创建时**的初始变换，并把仿真时钟归零；见下方说明 |
| 添加立方体 | 创建一个 1×1×1 的立方体网格并附加动态刚体，成功时提示“立方体添加成功” |
| 添加球体 | 创建一个半径 0.5 的球体网格并附加动态刚体，成功时提示“球体添加成功” |
| 导入模型 | 跳转到 `/model-library` 并带上 `returnUrl` 查询参数，在模型库选定模型后返回并自动导入 |
| 删除选中对象 | 删除当前选中的物体；没有选中物体时按钮为灰色 |
| 保存场景 | 弹出输入框索取场景名称，然后写入浏览器 `localStorage` |

“添加立方体”“添加球体”“导入模型”“保存场景”这四个按钮在场景尚未初始化完成时是禁用的。

### 关于“重置模拟”

这个按钮调用仓库的 `store.resetSimulation()`，它做三件事：

1. **停掉循环**：取消 store 那条 `requestAnimationFrame` 循环（`stopSimulation()`）；如果之前在播放，随后重新拉起（`startSimulation()`）。循环始终会重新排期，暂停只是不推进物理，因此不会把「暂停」变成「再也起不来」。
2. **把每个物体复位到创建时的初始变换**：物体在创建时（`addObject`）就记下了一份初始位置/旋转/缩放，重置时通过 `update-transform` 事件把这份初始变换写回 Rapier 刚体——`setTranslation` 复位位置、`setLinvel(0)` 与 `setAngvel(0)` 清零线速度与角速度，缩放则重新作用到碰撞体形状上。mesh 上的位置与旋转由刚体回写（Rapier 是位置的唯一权威），所以画面上也是回到初始位置。
3. **把仿真时钟归零**：`simulationState.currentTime` 与 `frameCount` 归零，`renderState.lastFrameTime` 清零。

它**不会**做的事：

- 不会重建 Rapier 物理世界——刚体、碰撞体、地面都还在原地，只是被复位了。
- 不会撤销“添加立方体/球体/导入模型”——物体仍然在场景里，只是回到了各自的初始位置。
- 不会改动你在属性面板里设置过的名称与可见性。

> ⚠️ 复位的基准是**创建时**的位置，不是属性面板里最后设定的位置。`SceneObject.position` 这个字段只表示「用户最后一次通过属性面板设定的位置」——物理同步从不写它，仿真中的下落也不会回写它。

## 属性面板

在 3D 视口中点击一个物体即可选中它（被选中的物体会呈黄色高亮），属性面板随之切换为编辑表单；未选中时显示“未选择任何对象 / 点击3D视图中的物体进行编辑”。

| 字段 | 输入类型 | 说明 |
| --- | --- | --- |
| 名称 | 文本框 | 修改后失焦时写回 |
| 位置 X / Y / Z | 数字，步进 0.1 | 世界坐标位置 |
| 旋转 X / Y / Z | 数字，单位为度，步进 1 | 内部换算成弧度后写入 |
| 缩放 X / Y / Z | 数字，步进 0.1，最小 0.1 | 缩放比例 |

属性面板**没有**质量、摩擦系数、恢复系数（弹性）这些控件，也没有“启用物理特性”的开关。场景编辑器当前无法为单个物体单独设置物理参数。

> 由于面板里没有任何物理参数控件，场景编辑器里的物体使用的是引擎默认值：碰撞体由创建函数直接决定（立方体为 `cuboid(0.5, 0.5, 0.5)`，球体为 `ball(0.5)`），摩擦系数与恢复系数沿用 Rapier 碰撞体默认值。

## 物理模拟在场景编辑器里如何运行

场景编辑器里只有**一套**物理：**Rapier**。

- 步进由 `useSceneEditor` 的 `updatePhysics` 驱动，渲染循环每帧把 `requestAnimationFrame` 的时间戳传进去。
- 时间步长是**固定的 1/60 秒**（`src/config/simulation.ts` 的 `simulationConfig.physics.fixedTimeStep`）。真实时间先累加到一个「累加器」里，再按固定步长切成若干个物理步——因此**仿真速度与显示刷新率无关**：60Hz 屏每秒推进 60 个物理步，30Hz 屏也是 60 个（低帧率时一帧多推几步）。单帧最多补 `maxSubSteps`（5）步，剩余积压会被丢弃，避免低帧率机器陷入“追帧→更卡→更少帧”的死循环。
- `simulationState.speed` 的语义是“每秒执行多少个固定步”：1× 就是每秒 60 步，2× 就是每秒 120 步。
- 每个物理步之后，`syncPhysicsToObjects` 把刚体的位移与四元数写回 `threeObject`——**Rapier 是位置的唯一权威**。
- `simulationState.currentTime` 记的是“模拟了多久”，`frameCount` 记的是“推进了多少个物理步”，两者都由固定步长累加器推进，与屏幕刷了多少帧无关。

因此在仿真播放期间，你在属性面板里手工设置的位置会被物理计算覆盖，输入框随即显示物理算出来的坐标。想让手工摆放的结果稳定可见，请先点击工具栏的“暂停模拟”再修改。

## 场景的保存与加载

点击**保存场景**后，浏览器弹出输入框询问场景名称。确认后，仓库的 `saveScene()` 把以下内容序列化成 JSON 写入 `localStorage`：

- 场景名称
- 物体列表，每个物体记录 `uuid`、`type`、`name`、`modelId`、`position`、`rotation`、`scale`、`visible`
- 一个 ISO 格式的时间戳

存储键名形如 `scene-scene-<时间戳>`。

> 重要限制：**界面上没有任何“已保存场景”的列表，也没有“加载场景”按钮。** 保存之后除非直接访问带 `sceneId` 查询参数的地址，否则无法在界面里找回这个场景。即使走查询参数这条路，加载逻辑也只会重建类型为 `model` 且带 `modelId` 的物体；立方体、球体等几何体在源码中留有“处理其他类型物体”的占位注释，实际不会被还原。

## 从模型库导入模型

点击**导入模型**后，系统会记住当前地址并跳转到模型库。在模型库中选中一个模型并触发“添加到场景编辑器”后返回场景编辑器，工具栏会监听到路由变化，自动调用 `importModel(modelId)` 完成导入，并提示导入成功或失败。

导入的模型会创建一个包围盒近似的长方体碰撞体。

## 当前限制汇总

- 属性面板没有质量、摩擦、弹性等物理参数控件。
- “重置模拟”会把物体复位到**创建时**的初始变换（刚体位置、速度与碰撞体形状一起复位），但不重建物理世界、也不撤销已添加的物体。
- 保存场景后没有列表 UI 可以找回，加载也只覆盖模型类型的物体。
- 物理只有 Rapier 一套，但手工设置的位置在播放时仍会被物理计算覆盖。
- 初始场景会自动添加两个立方体（ThreeScene 组件与场景编辑器页面各触发一次添加）。
- 导入模型只对模型库中 `modelUrl` 指向真实文件的条目有效。
