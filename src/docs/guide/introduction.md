# 3D场景编辑与仿真系统

欢迎使用3D场景编辑与仿真系统。本系统提供了一套用于创建、编辑3D场景、进行物理仿真并观察智能体决策的工具链。

本页是总览入口。各模块的细节见左侧导航栏中的相应章节；下面先说明系统当前**实际具备**的能力边界，再给出上手步骤。

## 系统功能概述

本系统包含以下四个模块：

1. **场景编辑器**（`/scene-editor`）：构建和编辑3D场景，添加立方体与球体、从模型库导入模型、调整位置/旋转/缩放，并运行物理模拟。
2. **仿真实验室**（`/simulation-lab`）：运行和观察物理仿真，调整重力、摩擦力、弹性系数与仿真速度，记录并导出实验数据。
3. **模型库**（`/model-library`）：按分类浏览3D模型资产、搜索与排序，并把可用模型送入场景编辑器。
4. **AI演武场**（`/ai-playground`）：配置环境、创建智能体、启动仿真并查看决策日志。3D 视图**会真实渲染**：智能体是 Rapier 刚体，会跑、会撞；决策由本地规则产生，可以选配 LLM。

> 需要留意的几处限制：场景编辑器的属性面板没有质量/摩擦/弹性等单物体物理参数控件；模型库的 9 个内置条目**全部指向真实 GLB**（都能真正加载），但上传的条目只在当前会话有效，刷新即失效；AI演武场默认不调用外部模型、也不做训练。各章节的《当前限制》一节有完整说明。

## 快速开始

### 第一步：创建场景

1. 点击导航栏中的"场景编辑器"进入场景编辑界面
2. 进入时场景是空的（不会自动添加立方体），物理模拟也**不会**自动开始——要让它跑起来，点工具栏的「开始模拟」
3. 使用顶部工具栏的"添加立方体""添加球体"按钮添加几何体
4. 需要模型时，点击工具栏的"导入模型"按钮跳转到模型库，在模型库中选定模型后会自动带回场景：模型库把模型 id 记进 `modelStore.selectedModelId` 并跳回，场景就绪后自动导入，并连同 Rapier 刚体与包围盒碰撞体一起建好
5. 在3D视口中点击物体选中它，在右侧属性面板调整位置、旋转与缩放

> 场景编辑器没有添加灯光或相机的界面。环境光、平行光、网格辅助线与轨道相机都在初始化时自动创建。

### 第二步：调整位置、旋转与缩放

1. 在场景编辑器中点击3D视图里的物体将它选中
2. 在右侧属性面板中修改"位置 X/Y/Z"、"旋转 X/Y/Z"（单位为度）与"缩放 X/Y/Z"
3. 修改后让输入框失焦（点击别处或按回车）即可生效
4. 点击工具栏的"保存场景"按钮填写场景名称，场景数据会存入浏览器的本地存储

> 属性面板没有质量、摩擦系数与弹性（恢复系数）等物理参数控件，也没有为单个物体开关物理特性的选项。这些参数在仿真实验室的"实验参数"面板里按全局生效。
>
> 保存后的场景可以在右侧属性面板底部的「我的场景」列表里找回：点名称打开、点「✕」删除。打开时重建**全部**类型的物体——几何体经工厂连刚体一起还原，模型按 `modelId` 重新加载，详见《场景编辑器使用指南》。

### 第三步：运行仿真

1. 点击导航栏中的"仿真实验室"
2. 在工具栏右侧的预设下拉框中选择预设（牛顿摆、斜坡与球体、碰撞测试 · 多形状、自由落体、双立方体碰撞、钟摆，共 6 个），也可以直接使用页面自带的演示场景
3. 点击"开始仿真"按钮运行物理仿真，可用"单步仿真"逐帧推进
4. 拖动"仿真速度"滑块调整快慢，在右侧"实验参数"面板调整重力、摩擦力与弹性系数
5. 勾选"记录仿真数据"并设置采样间隔，再点击"导出数据"下载 JSON 文件

> 场景编辑器保存的场景存入浏览器本地存储，仿真实验室的工具栏下拉框里可以选到它们；预设下拉框提供 6 个内置场景。此外，工具栏上「从场景编辑器加载场景」按钮会真的读取已保存的场景文档并重建场景（几何体与模型都还原），不再只是生成两个固定的演示物体。

### 第四步：观察AI决策（可选）

1. 点击导航栏中的"AI演武场"
2. 在"环境配置"面板设置场景类型、难度、障碍物密度、时间限制与胜利条件：改动**立即生效**（障碍物密度按 150 毫秒防抖，因为它要重建整块场地），点"应用设置"则一次性提交全部字段
3. 在"AI控制器"面板点击"添加代理"创建智能体，选中后调整速度、反应时间、感知范围等参数
4. 在右侧"调试信息"面板点击"开始"，观察"代理日志"中持续出现的决策记录

> 当前智能体行为由本地逻辑产生，默认不调用外部模型，系统也没有训练模型导入的功能。决策**会真的驱动物体运动**：`executeAgentDecision` 把决策写成期望速度，转向控制器再把期望速度换算成冲量施加到刚体上，由物理引擎积分出位移；中间的 3D 视图**正常渲染**。
