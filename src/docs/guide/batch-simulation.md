# 批量仿真使用指南

批量仿真（仿真实验室右栏的「批量仿真」面板）把**同一个场景按一组参数跑很多遍**，产出可以横向对照的结果。

它是一个**可选增强**：后端不在时，面板只会显示一句「后端不在，批量仿真暂不可用」，页面里其它功能（实时仿真、场景编辑、参数调节）完全不受影响。

## 前提：后端与队列

批量仿真由后端执行，需要两样东西同时就位：

1. **后端服务**：`cd backend && uv run uvicorn app.main:app --port 8000`
2. **队列 worker**：批量仿真走 Redis 队列，要另起一个进程
   ```bash
   cd backend
   uv run arq app.workers.simulation.WorkerSettings
   ```

面板顶部会显示「后端在线 · 最近 N 个任务」或「后端不在」。队列不通时提交任务会拿到 503 `simulation_queue_unavailable`，面板会直接告诉你队列没连上，而不是假装排队成功。

> Redis 连不上时，`POST /api/simulations` 立刻返回 503。任务不会被收下。

## 面板里的字段

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| 场景来源 | 本地场景库 | 可切到「粘贴场景文档」，直接贴一段场景 JSON |
| 场景 | 场景库第一项 | 场景库来自场景编辑器保存过的场景；一个都没存过时只能走粘贴 |
| 步数 | 240 | 每次运行推进多少个物理步 |
| 步长 dt | 1/60 秒 | 固定步长；改成别的值就不再与浏览器端逐位一致 |
| 重力 Y | -9.81 | 只作用于 Y 轴 |
| 摩擦 / 弹性 | 留空 | **留空表示不覆盖**，用引擎默认值；填了才生效 |
| 扫描维度 | 不扫描 | 可选：重力 / 摩擦 / 弹性 / 初始竖直速度 |
| 取值 | 空 | 逗号分隔，例如 `0.1, 0.5, 0.9` |
| 任务名 | 空 | 只用于列表里辨认 |
| 轨迹 | 不记录 | 改成「逐帧记录」后结果里会带上逐帧位置（体积会明显变大） |

**扫描一次只扫一个维度**，不是笛卡尔积：选了「摩擦」再填 `0.1, 0.5, 0.9`，就是跑 3 次，每次摩擦不同，其余参数相同。

## 结果怎么看

提交后面板会轮询任务状态，完成后给出两部分：

- **结果汇总**：运行次数、其中多少次真正落地、最大穿透深度
- **每次运行一行**：该轮生效的扫描参数、耗时（毫秒）、落地帧、最大穿透、下落距离

「落地」指物体在步数耗尽前已经静止贴地。**最大穿透**不为 0 说明物理配置有问题（正常情况是 0）。

## 与浏览器的一致性

后端用的是**与前端同一套物理引擎**（Rapier），并且把参数映射成与浏览器完全相同的形式。为了能验证这一点，仓库里放了一份**浏览器实跑基线**（`backend/tests/fixtures/browser_baseline.json`）：同样的场景、同样的参数，在浏览器里跑一遍把轨迹记下来，后端再跑一遍逐点比对。

当前基线的比对结果：

- 自由落体段（触地前）**逐位相同**
- 落地之后的最大偏差 **0.004971 米**（容差 0.02 米）

偏差来自接触求解器在两个运行环境里的细微差别，量级在毫米级。

> 所以：**别改步长 dt**。改成别的值之后，浏览器与后端就不再是同一套参数，一致性基线也就失去意义。

## 接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/api/simulations` | 提交一次批量仿真，返回 202 与 `jobId` |
| `GET` | `/api/simulations` | 最近 50 条任务 |
| `GET` | `/api/simulations/{jobId}` | 单个任务的状态与进度 |
| `GET` | `/api/simulations/{jobId}/results` | 该任务的全部运行结果与汇总 |

完整的接口文档见 [`docs/api-contract.md`](../../docs/api-contract.md)（由后端代码生成，CI 校验一致）。

## 限制与边界

| 限制 | 表现 |
| --- | --- |
| 只支持立方体与球体 | 其它物体类型（如模型）被跳过；场景里一个可渲染物体都没有时任务判为场景无效 |
| 单个任务最多 32 次运行 | 超出返回 422 `simulation_invalid_params` |
| 单次运行最多 10000 步 | 超出返回 422 `simulation_invalid_params` |
| 每天最多 2000 次运行 | 按当天已产生的运行次数计，超出返回 429 `simulation_quota_exceeded` |
| 必须有队列 worker | 队列不通 → 503 `simulation_queue_unavailable` |
| 后端不在时功能不可用 | 面板给出说明，其余页面功能不受影响 |
| 帧数与步数不是一回事 | 步数是**物理步**，不是渲染帧；一次物理步对应一帧渲染 |
