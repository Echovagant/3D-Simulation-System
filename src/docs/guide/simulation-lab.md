# 仿真实验室使用指南

仿真实验室（路由 `/simulation-lab`）是一个独立的物理实验台：选择一个内置场景、运行仿真、调整实验参数、记录数据并导出。

它**不依赖**场景编辑器，两边各自拥有独立的 Three.js 场景与物理世界。

## 页面结构

- **顶部**：页面标题栏，以及居中的消息提示条（操作反馈显示 3 秒后自动消失）。
- **主区域上方**：仿真控制工具栏，含播放控制、速度滑块、场景加载与保存按钮、预设下拉框。
- **主区域中央**：3D 视口，左上角浮层显示“物体数量: N | FPS: N”。
- **主区域下方**：状态面板，显示仿真状态、仿真时间、物体数量与 FPS。
- **右侧**：实验参数面板（宽 320 像素）。

## 预设场景

工具栏右侧的下拉框默认显示“选择预设...”，展开后有 3 个内置场景：

| 预设 | 内容 |
| --- | --- |
| 自由落体 | 一个立方体与一个球体，起始高度均为 5，X 分别为 0 与 2 |
| 碰撞测试 | 两个立方体，X 分别为 -2 与 2，高度为 1 |
| 钟摆 | 一个名为“摆球”的方块，缩放 0.5，位于高度 3 |

选择后会移除现有物体、创建预设中的物体、重新初始化物理世界并把仿真时间归零。

> 关于“钟摆”：该预设目前只是一个放在半空的方块，并没有实现摆的约束关系——它和其他预设一样，只是自由落体。

## 仿真控制

工具栏左侧的按钮组从左到右为：

| 按钮 | 作用 |
| --- | --- |
| 开始仿真 / 暂停仿真 | 切换运行状态，图标随状态变化 |
| 单步仿真 | 手动推进一帧 0.016 秒，仿真时间同步增加 0.016 秒 |
| 重置仿真 | 停止仿真、时间归零、移除全部物理物体、重建物理世界，并重新加载当前预设（未选预设时加载演示场景） |
| 删除选中物体 | 删除当前选中的物体，未选中时按钮为灰色 |

中间的**仿真速度**滑块范围 0.1 到 5.0，步进 0.1，右侧显示当前倍率。速度的实际作用是放大每帧步长：推进步长为 `0.016 × 倍率`，仿真时间按同一数值累加。

在 3D 视口中点击物体即可选中它，物体变为黄色，右侧面板随之显示该物体的名称、位置与旋转。

## 实验参数

右侧面板的“环境设置”分组提供三个参数，修改后失焦即生效：

| 参数 | 默认值 | 生效范围 |
| --- | --- | --- |
| 重力 | -9.8 | 写入物理世界的重力向量，只作用于 Y 轴 |
| 摩擦力 | 0.1 | 遍历场景，更新所有碰撞体的摩擦系数 |
| 弹性系数 | 0.5 | 遍历场景，更新所有碰撞体的恢复系数 |

摩擦力与弹性系数是**批量生效**的：它们会同时作用于场景中的每一个物理物体，不能只针对单个物体设置。

每次修改都会在页面顶部弹出提示，例如“弹性系数已设置为 0.5”。

## 数据记录与导出

“数据记录”分组提供：

1. **记录仿真数据**：勾选后开始采集。数据只在仿真运行中产生。
2. **采样间隔**：单位为秒，最小 0.01，默认 0.1。实际采样时刻由仿真时间累积决定。
3. **已记录: N 帧**：显示已采集的帧数。
4. **导出数据**：帧数大于 0 时出现。点击后浏览器下载 `simulation-data-<时间戳>.json`，内容是按时间排列的帧记录，每帧含时间戳与各物理物体当时的位置。

## 保存实验配置

工具栏上的**保存实验配置**按钮会把当前的重力、摩擦力、弹性系数、仿真速度、是否记录数据、采样间隔打包写入 `localStorage`，键名为 `experimentConfig`，随后提示“实验配置已保存”。

> 限制：当前界面**没有读取该配置的入口**，刷新页面后参数会恢复默认值。

## “从场景编辑器加载场景”按钮的真实行为

工具栏上还有一个文件夹图标按钮，标题为“从场景编辑器加载场景”。它的实际行为是：

1. 移除场景中全部物理物体；
2. 创建两个**硬编码的演示物体**——“演示立方体”（位置 `(0, 3, 0)`）与“演示球体”（位置 `(2, 3, 0)`）；
3. 重新初始化物理世界，仿真时间归零；
4. 提示“已加载演示场景”。

> 重要限制：这个按钮**不会读取场景编辑器保存的场景**。场景编辑器确实把场景写进了 `localStorage`，但仿真实验室的代码里没有任何读取它的逻辑，按钮名与实际行为并不一致。
>
> 页面首次进入时也会自动执行一次同样的演示场景创建，因此不选预设也能直接开始仿真。

## 当前限制汇总

- “从场景编辑器加载场景”不加载场景编辑器的内容，只生成固定演示物体。
- “保存实验配置”保存后没有读取入口。
- “钟摆”预设没有实现摆的约束。
- 摩擦力与弹性系数按全局批量生效，无法只调某一个物体。
- 速度调高会同步放大单帧步长，长时间运行下数值稳定性会下降。
