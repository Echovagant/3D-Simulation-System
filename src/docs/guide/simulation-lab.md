# 仿真实验室使用指南

仿真实验室（路由 `/simulation-lab`）是一个独立的物理实验台：选择一个内置场景、运行仿真、调整实验参数、记录数据并导出。

它**不依赖**场景编辑器，两边各自拥有独立的 Three.js 场景与物理世界。

## 页面结构

- **顶部**：页面标题栏，以及居中的消息提示条（操作反馈显示 3 秒后自动消失）。
- **主区域上方**：仿真控制工具栏，含播放控制、速度滑块、场景加载与保存按钮、预设下拉框。
- **主区域中央**：3D 视口，左上角浮层显示“物体数量: N | FPS: N”（FPS 取最近 30 帧的滑动窗口平均，不是单帧耗时的倒数）。
- **主区域下方**：状态面板，显示仿真状态、仿真时间、物体数量与 FPS。
- **右侧**：实验参数面板（宽 320 像素）。

## 预设场景

工具栏右侧的下拉框默认显示“选择预设...”，展开后有 6 个内置场景：

| 预设 | 内容 |
| --- | --- |
| 牛顿摆 | 一个“支架”与 5 个“摆球 N”，摆球沿 X 排成一列 |
| 斜坡与球体 | 一块“地面”、一块“斜坡”与 3 个大小不同的球体 |
| 碰撞测试 · 多形状 | 一块“地面”、一个“立方体”、一个“球体”与一个“圆柱体” |
| 自由落体 | 一个“立方体”与一个“球体”，起始高度均为 5，X 分别为 0 与 2 |
| 双立方体碰撞 | 两个立方体，X 分别为 -2 与 2，高度为 1 |
| 钟摆 | 一个名为“摆球”的方块，缩放 0.5，位于高度 3 |

选择后会移除现有物体、创建预设中的物体、重新初始化物理世界并把仿真时间归零。

> 关于“钟摆”：该预设目前只是一个放在半空的方块，并没有实现摆的约束关系——它和其他预设一样，只是自由落体。

## 仿真控制

工具栏左侧的按钮组从左到右为：

| 按钮 | 作用 |
| --- | --- |
| 开始仿真 / 暂停仿真 | 切换运行状态，图标随状态变化 |
| 单步仿真 | 手动推进一个固定步长（1/60 秒，约 0.0167 秒），仿真时间同步增加同样的数值 |
| 重置仿真 | 停止仿真、时间归零、移除全部物理物体、重建物理世界，并重新加载当前预设（未选预设时加载演示场景） |
| 删除选中物体 | 删除当前选中的物体，未选中时按钮为灰色 |

中间的**仿真速度**滑块范围 0.1 到 5.0，步进 0.1，右侧显示当前倍率。速度是**倍率**：1× 表示仿真时间与真实时间同步，2× 表示同样的真实时间里推进 2 倍的仿真时间。**物理步长恒为 1/60 秒**，倍率改变的只是“每秒推进多少个步”，不改变步长本身。

> 倍率越高，同样的真实时间内推进的物理步越多：5× 时每真实秒约推进 300 步。步长不变，所以不存在“步长变大导致数值不稳定”的问题。单个渲染帧最多推进 `maxSubSteps`（5）步，多余的积压会被丢弃（否则低帧率机器会陷入“追帧→更卡→更少帧”的死循环）。

在 3D 视口中点击物体即可选中它，物体变为黄色，右侧面板随之显示该物体的名称、位置与旋转。

## 实验参数

右侧面板的“环境设置”分组提供三个参数，修改后失焦即生效：

| 参数 | 默认值 | 生效范围 |
| --- | --- | --- |
| 重力 | -9.8 | 写入物理世界的重力向量，只作用于 Y 轴 |
| 摩擦力 | 0.1 | 遍历场景，更新所有碰撞体的摩擦系数 |
| 弹性系数 | 0.5 | 遍历场景，更新所有碰撞体的恢复系数 |

摩擦力与弹性系数是**批量生效**的：它们会同时作用于场景中的每一个物理物体，不能只针对单个物体设置。

> 补充：面板里摩擦力与弹性系数的**默认值不会一进页面就下发**——那样会把预设里逐个物体的参数抹平。只有你真的动过这两个输入框（或恢复了已保存的实验配置），它们才会作为全局覆盖生效。

每次修改都会在页面顶部弹出提示，例如“弹性系数已设置为 0.5”。

## 数据记录与导出

“数据记录”分组提供：

1. **记录仿真数据**：勾选后开始采集。数据只在仿真运行中产生。
2. **采样间隔**：单位为秒，最小 0.01，默认 0.1。实际采样时刻由仿真时间累积决定。
3. **已记录: N 帧**：显示已采集的帧数。
4. **导出数据**：帧数大于 0 时出现。点击后浏览器下载 `simulation-data-<时间戳>.json`，内容是按时间排列的帧记录，每帧含时间戳与各物理物体当时的位置。

## 保存实验配置

工具栏上的**保存实验配置**按钮会把当前的重力、摩擦力、弹性系数、仿真速度、是否记录数据、采样间隔打包写入 `localStorage`，键名为 `experimentConfig`，随后提示“实验配置已保存”。

**这份配置会被读回**：下次打开仿真实验室时，页面初始化阶段会读出上次保存的 6 项参数并填回界面，重力、摩擦力与弹性系数同时**真正作用到物理世界**上（物理世界建好后会重新下发一次），仿真速度也照常生效。数据损坏时保持默认值，不会让页面崩。

> 限制：配置只存在于浏览器的 `localStorage` 里，换浏览器、换设备或清掉站点数据就没了。

## “从场景编辑器加载场景”按钮的真实行为

工具栏右侧有两个配合使用的控件：一个标题为“选择已保存场景...”的下拉框，以及一个文件夹图标按钮，标题为“从场景编辑器加载场景”。

1. 下拉框列出场景编辑器保存过的场景（格式 `<名称>（<N> 个物体）`）；一个都没保存过时，按钮是禁用的。
2. 选中场景后点按钮：移除当前所有物体，**读取场景编辑器真正存下来的场景文档**（`localStorage` 里的 `scene-<id>`），按文档记录的位置、旋转与缩放重建物体，模型按 `modelId` 重新加载，随后重新初始化物理世界并把仿真时间归零，提示“已从场景编辑器加载: <名称>”。
3. 没有先在下拉框里选场景就点按钮，提示“请先在工具栏里选择一个已保存的场景”。

> 限制：从编辑器加载过来的物体使用实验室侧的默认摩擦力与弹性系数（0.5 / 0.2）——场景编辑器本身没有单物体的物理参数控件，也就不会保存这些值。

> 页面首次进入时也会自动创建两个**硬编码的演示物体**——“演示立方体”（位置 `(0, 3, 0)`）与“演示球体”（位置 `(2, 3, 0)`），因此不选预设也能直接开始仿真。点「重置仿真」而当前没有选预设时，跑的也是同一段演示场景创建逻辑。

## 当前限制汇总

- “从场景编辑器加载场景”需要先在下拉框里选中一个场景；一个场景都没保存过时按钮是禁用的。
- “保存实验配置”的内容只存在浏览器的 `localStorage` 里，换设备或清掉站点数据就没了。
- “钟摆”预设没有实现摆的约束。
- 摩擦力与弹性系数按全局批量生效，无法只调某一个物体。
- 从场景编辑器加载过来的物体使用实验室侧的默认摩擦力与弹性系数（0.5 / 0.2）。
