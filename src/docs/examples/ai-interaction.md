# AI交互示例

本示例在**AI演武场**里完成一次智能体实验：配置环境、创建智能体、启动仿真、查看决策日志。

文中每一步都对应页面上真实存在的按钮或输入框，不含任何需要复制粘贴的代码。

> 阅读前请先了解当前实现的真实状态：**智能体的行为由本地随机逻辑产生，不是外部模型推理结果**；中间的 3D 视图区域目前也不会渲染出任何 3D 内容。本示例描述的是这些功能当前**确实存在**的行为。

## 第一步：进入 AI 演武场

点击顶部导航栏中的**AI演武场**，进入 `/ai-playground` 页面。页面分为四个区域：

- 左侧上方：**环境配置**面板
- 左侧下方：**AI控制器**面板
- 中间：**3D环境视图**区域
- 右侧：**调试信息**面板

进入页面后，系统会自动创建一个名为“导航机器人”的基础型智能体，因此 AI 控制器的代理列表一开始不是空的。

## 第二步：配置环境

在“环境配置”面板中依次设置：

1. **场景类型**：下拉框，四个选项分别是导航挑战、物体交互、对抗模拟、自定义场景。
2. **难度级别**：三个单选按钮——简单、中等、困难。
3. **障碍物密度**：取值 0 到 1 的滑块，右侧以百分比显示。
4. **时间限制**：数字输入框，单位为秒，0 表示无限制。
5. **胜利条件**：文本输入框。

设置完成后点击**应用设置**，配置才会写入状态仓库。

> 重要限制：各个输入框的即时更新回调目前是空函数。也就是说，**在点击“应用设置”之前，修改的内容不会生效**；调试面板右上角显示的“场景类型”和“难度”也只有在应用之后才会更新。

## 第三步：创建与管理智能体

在“AI控制器”面板中：

1. 点击代理列表右上角的**添加代理**，会新建一个名为“AI代理 N”的基础型智能体（序号按列表数量递增）。
2. 点击列表中的任意智能体即可选中它，选中项有高亮边框。
3. 选中智能体后，下方出现参数设置区，可调项按类型区分：

| 参数 | 适用类型 | 取值范围 |
| --- | --- | --- |
| 移动速度 | 基础型 | 1 到 10，步进 0.5 |
| 反应时间 (s) | 基础型、高级型 | 0.1 到 2，步进 0.1 |
| 感知范围 | 基础型、高级型 | 1 到 20，步进 1 |
| 避障 | 基础型、高级型 | 开关 |
| 启用学习 | 高级型 | 开关 |
| 记忆保留 (s) | 高级型 | 10 到 300，步进 10 |

这些参数会写回智能体的参数表，并被决策逻辑读取——例如基础型智能体决策时的速度就取自“移动速度”。

4. 点击**移除代理**可删除当前选中的智能体。删除最后一个智能体后选中状态会被清空。

> 限制：界面上只能创建“基础型”智能体。“高级型”与“自定义类型”的参数区虽然存在，但目前没有创建入口——它们只能通过代码调用接口创建。

## 第四步：运行仿真并查看决策

在右侧“调试信息”面板中：

1. 点击**开始**（绿色按钮）。仿真状态变为运行中，所有智能体状态变为 `running`，并各自写入一条“仿真开始”日志。
2. 面板顶部实时显示**仿真时间**与**活跃代理**数量。
3. 每隔约 100 毫秒，系统会为每个运行中的智能体生成一条决策，并写入该智能体的日志，形如 `决定: move {"direction":[...],"speed":5}`。
4. 点击**暂停**（红色按钮）停止生成决策；点击**重置**把仿真时间归零、状态复位；点击**清空日志**擦掉所有代理的历史日志。
5. “代理日志”区右侧的下拉框可按类型过滤：所有日志、信息、警告、错误。

决策内容按智能体类型生成：基础型总是产生 `move`，方向是随机向量；高级型有 70% 概率 `move`、20% 概率 `rotate`、10% 概率 `wait`；自定义类型固定向 `[0, 0, 1]` 移动。置信度落在 0.5 到 1.0 之间。

> 重要限制：这些决策**不会真正驱动物体运动**。决策的“执行”入口 `executeAgentDecision` 目前是空实现，且整个代码库中没有任何地方调用它。决策只停留在队列与日志里。

## 第五步：关于 3D 视图区域

中间的“3D环境视图”区域目前不会显示任何 3D 画面。原因是渲染循环调用渲染器时所持的渲染器实例始终为空——渲染器实际由另一个独立的渲染器组合式函数创建，与循环读取的不是同一个实例；同样地，轨道控制器因为拿不到相机与渲染器而没有被创建，页面上的视角操作提示（拖动旋转、滚轮缩放）因此也不生效。

页面上的“正在初始化物理引擎和 AI 系统”加载提示会在约 2 秒后消失；物理世界确实被创建并推进，但没有任何可被观察到的 3D 表现。

因此在这一页，当前能真正验证的产出是**环境配置、代理参数与决策日志**这三部分，而不是画面里的运动。
