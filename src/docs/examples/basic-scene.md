# 基础场景示例

本示例一步步带你用**场景编辑器**搭出一个包含立方体和球体的 3D 场景，并调整它们的位置、旋转与缩放。

文中每一步都对应页面上真实存在的按钮或输入框，不含任何需要复制粘贴的代码。

## 准备：进入场景编辑器

1. 点击顶部导航栏中的**场景编辑器**，进入 `/scene-editor` 页面。
2. 页面中央会出现“SceneEditor场景初始化中...”的加载提示。初始化期间，左侧工具栏里的“添加立方体”“添加球体”“导入模型”“保存场景”四个按钮是灰色不可点击的。
3. 若初始化失败，页面会显示错误信息和一个“重试”按钮，点击即可重新初始化。

初始化成功后系统会**自动开启物理模拟**，但**不会添加任何物体**：进入页面时场景是空的——地面、灯光与网格辅助线照常创建，但没有任何正在下落的物体。

> 说明：早期的版本会在初始化后自动塞进立方体（ThreeScene 组件与场景编辑器页面各触发一次），所以初始画面里常见两个立方体。这个行为已经去掉了，场景从空开始。

## 第一步：添加几何体

左侧工具栏顶部是场景控制按钮，其下是物体添加按钮组：

1. 点击**添加立方体**（方块图标）。工具栏右侧会提示“立方体添加成功”。
2. 点击**添加球体**（圆形图标）。提示“球体添加成功”。

新物体的初始位置是随机的：X 与 Z 落在 `(-2.5, 2.5)` 区间，高度固定为 2，颜色也随机生成。

## 第二步：选中并编辑属性

1. 在 3D 视口中**直接点击**一个物体。命中后该物体会被选中，右侧属性面板随之切换到编辑表单。
2. 如果没有选中任何物体，属性面板显示“未选择任何对象 / 点击3D视图中的物体进行编辑”。
3. 右侧属性面板中可编辑的字段如下：

| 字段 | 输入类型 | 说明 |
| --- | --- | --- |
| 名称 | 文本框 | 修改后在输入框失焦时写回 |
| 位置 X / Y / Z | 数字，步进 0.1 | 物体在世界坐标中的位置 |
| 旋转 X / Y / Z | 数字，单位为**度**，步进 1 | 填入角度，内部会换算成弧度 |
| 缩放 X / Y / Z | 数字，步进 0.1，最小 0.1 | 物体的缩放比例 |

4. 改完数值后，**点击输入框外或按回车**让输入框失焦，数值才会生效。

> 重要限制：属性面板**没有**质量、摩擦系数、恢复系数（弹性）这几项控件。场景编辑器当前无法为单个物体设置这些物理参数——它们在仿真实验室的实验参数面板里是按全局生效的。
>
> 另一个限制：当物理模拟正在播放时，手工设置的位置会被物理计算覆盖，输入框随即显示物理算出来的坐标。如果希望手工摆放的结果稳定可见，请先点击工具栏的**暂停模拟**（播放/暂停图标）再修改——暂停只停**物理推进**，**渲染不会停**，所以你摆完的位置既不会被物理覆盖，也能立刻在画面上看到，视角照常可转。

## 第三步：调整视角

在 3D 视口中按住鼠标左键拖动可以旋转视角，滚轮缩放。相机由 `OrbitControls` 驱动，开启了阻尼（`dampingFactor` 为 0.05），松手后会有轻微的减速惯性。

## 第四步：删除与保存

1. 选中要删除的物体后，点击工具栏的**删除选中对象**（垃圾桶图标）。没有选中物体时该按钮是灰色的。
2. 点击工具栏的**保存场景**（软盘图标），浏览器会弹出输入框让你填写场景名称。填写后场景数据被写入浏览器的 `localStorage`，工具栏提示“场景保存成功: <名称>（ID: <场景 id>，可在右侧「我的场景」中打开）”。

已保存的场景在**右侧属性面板底部的「我的场景」**列表里找回：

1. 点场景名即可打开（`loadScene`），面板下方会提示“已加载场景：<名称>”。
2. 点场景名右侧的「✕」删除该场景（带确认框）。
3. 也可以直接访问带 `sceneId` 查询参数的地址（`/scene-editor?sceneId=<id>`）打开指定场景。

打开场景会重建**全部**类型的物体：立方体、球体等基本体通过界面层注册的工厂重新创建，**连同 Rapier 刚体与碰撞体一起建好**；模型按 `modelId` 重新加载。因此还原出来的方块照样会下落、会撞地面。

> 已知限制：基本体是“重新创建”的，**uuid 会变**（存档里的 uuid 不再复用）。

## 第五步：导入模型（可选）

1. 点击工具栏的**导入模型**（盒子图标）。系统会跳转到 `/model-library` 页面，并把当前地址作为返回参数带上。
2. 在模型库中点击卡片选中一个模型，在详情弹窗中点击**添加到场景编辑器**，或使用卡片右上角的加号按钮。
3. 模型库会把选中的模型 id 记进 `modelStore.selectedModelId` 并跳回场景编辑器；场景就绪后，工具栏取出这个 id 调用 `importModel(modelId)` 完成导入，工具栏提示“模型 "<名称>" 导入成功”或“导入失败”。**导入完成即清空这个 id**，所以同一个模型不会被重复导入。

导入的模型会建出动态刚体与**包围盒近似**的长方体碰撞体，因此它会下落、会与地面碰撞，而不是一个只会“出现在画面里”的空壳。

> 限制：只有 `modelUrl` 指向真实文件的模型能导入成功。模型库内 9 个内置条目全部指向仓库里真实存在的 GLB 文件，都能真正导入；本次会话上传的模型用 `blob:` 对象地址，同样可以导入。详见《模型库使用指南》。
