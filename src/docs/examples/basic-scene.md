# 基础场景示例

本示例一步步带你用**场景编辑器**搭出一个包含立方体和球体的 3D 场景，并调整它们的位置、旋转与缩放。

文中每一步都对应页面上真实存在的按钮或输入框，不含任何需要复制粘贴的代码。

## 准备：进入场景编辑器

1. 点击顶部导航栏中的**场景编辑器**，进入 `/scene-editor` 页面。
2. 页面中央会出现“SceneEditor场景初始化中...”的加载提示。初始化期间，左侧工具栏里的“添加立方体”“添加球体”“导入模型”“保存场景”四个按钮是灰色不可点击的。
3. 若初始化失败，页面会显示错误信息和一个“重试”按钮，点击即可重新初始化。

初始化成功后会发生两件事：系统自动添加立方体，并自动开启物理模拟。因此你看到的初始画面里通常已经有物体在下落。

> 说明：初始化完成后，ThreeScene 组件与场景编辑器页面各触发一次“添加立方体”，所以初始画面中一般是两个立方体。

## 第一步：添加几何体

左侧工具栏顶部是场景控制按钮，其下是物体添加按钮组：

1. 点击**添加立方体**（方块图标）。工具栏右侧会提示“立方体添加成功”。
2. 点击**添加球体**（圆形图标）。提示“球体添加成功”。

新物体的初始位置是随机的：X 与 Z 落在 `(-2.5, 2.5)` 区间，高度固定为 2，颜色也随机生成。

## 第二步：选中并编辑属性

1. 在 3D 视口中**直接点击**一个物体。命中后该物体会被选中，右侧属性面板随之切换到编辑表单。
2. 如果没有选中任何物体，属性面板显示“未选择任何对象 / 点击3D视图中的物体进行编辑”。
3. 右侧属性面板中可编辑的字段如下：

| 字段 | 输入类型 | 说明 |
| --- | --- | --- |
| 名称 | 文本框 | 修改后在输入框失焦时写回 |
| 位置 X / Y / Z | 数字，步进 0.1 | 物体在世界坐标中的位置 |
| 旋转 X / Y / Z | 数字，单位为**度**，步进 1 | 填入角度，内部会换算成弧度 |
| 缩放 X / Y / Z | 数字，步进 0.1，最小 0.1 | 物体的缩放比例 |

4. 改完数值后，**点击输入框外或按回车**让输入框失焦，数值才会生效。

> 重要限制：属性面板**没有**质量、摩擦系数、恢复系数（弹性）这几项控件。场景编辑器当前无法为单个物体设置这些物理参数——它们在仿真实验室的实验参数面板里是按全局生效的。
>
> 另一个限制：当物理模拟正在播放时，手工设置的位置会被物理计算覆盖，输入框随即显示物理算出来的坐标。如果希望手工摆放的结果稳定可见，请先点击工具栏的**暂停模拟**（播放/暂停图标）再修改。

## 第三步：调整视角

在 3D 视口中按住鼠标左键拖动可以旋转视角，滚轮缩放。相机由 `OrbitControls` 驱动，开启了阻尼（`dampingFactor` 为 0.05），松手后会有轻微的减速惯性。

## 第四步：删除与保存

1. 选中要删除的物体后，点击工具栏的**删除选中对象**（垃圾桶图标）。没有选中物体时该按钮是灰色的。
2. 点击工具栏的**保存场景**（软盘图标），浏览器会弹出输入框让你填写场景名称。填写后场景数据被写入浏览器的 `localStorage`，工具栏提示“场景保存成功: <名称>”。

> 重要限制：**当前界面没有提供已保存场景的列表**，也没有“加载场景”按钮。只有在直接访问带 `sceneId` 查询参数的地址时，场景编辑器才会尝试从 `localStorage` 读取并还原场景；而且还原逻辑只覆盖模型类型的物体，立方体、球体等不会被重建。
>
> 因此“保存场景”目前更像是一次数据落盘，而不是一个可往返的工作流。

## 第五步：导入模型（可选）

1. 点击工具栏的**导入模型**（盒子图标）。系统会跳转到 `/model-library` 页面，并把当前地址作为返回参数带上。
2. 在模型库中点击卡片选中一个模型，在详情弹窗中点击**添加到场景编辑器**，或使用卡片右上角的加号按钮。
3. 返回场景编辑器后，选中的模型会被自动导入场景，工具栏提示导入成功或失败。

> 限制：只有 `modelUrl` 指向真实文件的模型能导入成功。模型库中多数条目的 `modelUrl` 是 `#`，这类模型会直接加载失败，详见《模型库使用指南》。
