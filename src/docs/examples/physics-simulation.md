# 物理仿真示例

本示例在**仿真实验室**里完成一次完整的物理实验：选一个内置场景、运行仿真、调整参数、记录并导出数据。

文中每一步都对应页面上真实存在的按钮或输入框，不含任何需要复制粘贴的代码。

## 第一步：选择一个内置场景

仿真实验室顶部的工具栏右侧有一个预设下拉框，默认显示“选择预设...”。展开后有三个选项：

| 预设 | 包含的物体 |
| --- | --- |
| 自由落体 | 一个立方体和一个球体，起始高度均为 5 |
| 碰撞测试 | 两个立方体，分别位于 X 为 -2 与 2 处 |
| 钟摆 | 一个缩放为 0.5 的方块“摆球”，位于高度 3 处 |

选择任意一项后，画面中立刻生成对应的物体，同时重新初始化物理世界，仿真时间归零，页面顶部提示“已加载预设: <预设名>”。

## 第二步：运行与控制仿真

工具栏左侧的按钮组按从左到右的顺序是：

| 按钮 | 作用 |
| --- | --- |
| 播放 / 暂停 | 开始或暂停仿真，图标在两者间切换 |
| 单步仿真 | 手动推进一帧固定步长（0.016 秒），仿真时间同步增加 |
| 重置仿真 | 停止仿真、仿真时间归零、移除全部物理物体、重建物理世界，并重新加载当前预设 |
| 删除选中物体 | 删除当前选中的物体，没有选中时按钮为灰色 |

工具栏中间是**仿真速度**滑块，取值范围 0.1 到 5.0，步进 0.1，右侧实时显示当前倍率。速度作用于每帧推进的步长：实际步长为 `0.016 × 倍率`，仿真时间也按同一数值累加。

> 注意：速度调大时单帧步长会同步变大。例如倍率 5 时单帧推进约 0.08 秒，长时间运行下数值稳定性会下降。

## 第三步：调整实验参数

右侧的“实验参数”面板分两组：

**环境设置**

| 参数 | 默认值 | 生效方式 |
| --- | --- | --- |
| 重力 | -9.8 | 输入后失焦即写入物理世界的重力向量（只作用于 Y 轴） |
| 摩擦力 | 0.1 | 输入后失焦即遍历场景，更新所有碰撞体的摩擦系数 |
| 弹性系数 | 0.5 | 输入后失焦即遍历场景，更新所有碰撞体的恢复系数 |

每次修改都会在页面顶部弹出提示，例如“重力已设置为 -9.8”。

摩擦力与弹性系数是**按碰撞体批量更新**的，会同时作用到场景中的全部物理物体，不能针对单个物体单独设置。

## 第四步：记录并导出数据

“数据记录”分组提供三个控件：

1. 勾选**记录仿真数据**。该选项只有在仿真运行中才会开始产生数据。
2. 设置**采样间隔**（单位秒，最小 0.01，默认 0.1）。实际采样频率取决于仿真时间累积到多少才超过这个间隔。
3. 面板会显示“已记录: N 帧”。当帧数大于 0 时，**导出数据**按钮出现。

点击**导出数据**后，浏览器会下载一个名为 `simulation-data-<时间戳>.json` 的文件，内容是按时间排列的帧记录，每帧包含时间戳以及各物理物体当时的位置。

## 第五步：保存实验配置

点击工具栏上的**保存实验配置**（软盘图标），当前的重力、摩擦力、弹性系数、仿真速度、是否记录数据与采样间隔会被打包写入浏览器的 `localStorage`，键名为 `experimentConfig`，页面提示“实验配置已保存”。

> 限制：**当前界面没有读取这个配置的入口**。刷新页面后这些参数会恢复成默认值，已保存的配置需要手动打开浏览器开发者工具才能取回。

## 关于“从场景编辑器加载场景”按钮

工具栏上还有一个文件夹图标的按钮，标题为“从场景编辑器加载场景”。点击它会移除当前所有物体，然后生成两个**硬编码的演示物体**——“演示立方体”和“演示球体”，位置分别在 `(0, 3, 0)` 与 `(2, 3, 0)`，并重新初始化物理世界，页面提示“已加载演示场景”。

> 重要限制：这个按钮**并不读取场景编辑器保存的场景**。场景编辑器保存的数据虽然写在 `localStorage` 里，但仿真实验室没有任何读取它的代码。想在仿真实验室里复现自己的场景，目前只能把预设场景当作起点，再手动调整参数。

顺带一提，页面首次进入时也会自动执行一次这个演示场景的创建，因此不选预设也能直接开始仿真。
